# 📝 myincidentnotes

**myincidentnotes** es una aplicación web full-stack de gestión de notas e incidentes desarrollada con arquitectura moderna, enfocada en la sincronización en tiempo real, seguridad robusta y rendimiento optimizado.

---

## 🚀 Stack Tecnológico

* **Frontend / Framework:** [Next.js](https://nextjs.org/) (App Router, React, TypeScript)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
* **Base de Datos & Auth:** [Supabase](https://supabase.com/) (PostgreSQL, Row Level Security, Supabase Auth, Realtime)
* **Despliegue:** [Vercel](https://vercel.com/) (`myincidentnotes.vercel.app`)

---

## ✨ Características Principales

* 🔒 **Autenticación & Roles:** Registro, inicio de sesión seguro, soporte multi-dispositivo simultáneo y panel de administración para control de usuarios.
* ⚡ **Sincronización Realtime:** Auto-guardado en tiempo real (*debounce*) y actualización instantánea de cambios en múltiples dispositivos.
* 📂 **Organización Inteligente:** Cuadernos/Carpetas, Etiquetas (Tags), Notas Favoritas/Ancladas y Búsqueda Instantánea.
* 🗑️ **Papelera de Reciclaje:** Recuperación manual y purga automática de notas eliminadas a los 30 días.
* 📤 **Exportación & Compartir:** Descarga en formato `.txt` y compatibilidad con Web Share API.
* 🌗 **Interfaz adaptable:** Soporte nativo para Modo Oscuro y Modo Claro.
